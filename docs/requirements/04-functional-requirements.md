## 概要

本ドキュメントは、OpenMaaSプラットフォームの全機能要件をMoSCoW分析手法により優先順位付けし、開発スコープを明確化します。

### MoSCoW分析とは

**M**ust have（必須）、**S**hould have（重要）、**C**ould have（推奨）、**W**on't have（対象外）の4段階で機能の優先度を分類する手法です。

---

## MoSCoW分析の定義

### 📊 優先度分類基準

| 分類 | 説明 | 開発タイミング | リソース配分 | MVP含む |
|------|------|---------------|------------|---------|
| **Must Have** | サービス提供に必須。これがないと成立しない | Phase 1-2 | 60% | ✅ Yes |
| **Should Have** | 重要だが代替手段あり。大きな価値を提供 | Phase 3 | 25% | 部分的 |
| **Could Have** | あれば良い。差別化要素だが優先度低 | Phase 4-5 | 10% | ❌ No |
| **Won't Have** | 今回は対象外。次期バージョンで検討 | 将来 | 5% | ❌ No |

---

## API要件

### RESTful API 設計原則

1. **リソースベース設計**
   - URLはリソースを表現（動詞ではなく名詞）
   - `/api/v1/users`, `/api/v1/routes`, `/api/v1/tickets`

2. **HTTPメソッドの適切な使用**
   - GET: 取得
   - POST: 作成
   - PUT: 更新（全体）
   - PATCH: 更新（部分）
   - DELETE: 削除

3. **ステータスコードの統一**
   - 200: 成功
   - 201: 作成成功
   - 400: リクエストエラー
   - 401: 認証エラー
   - 403: 権限エラー
   - 404: 未検出
   - 500: サーバーエラー

### 主要エンドポイント

#### 認証 API

```
POST   /api/v1/auth/register        # ユーザー登録
POST   /api/v1/auth/login           # ログイン
POST   /api/v1/auth/logout          # ログアウト
POST   /api/v1/auth/refresh         # トークン更新
POST   /api/v1/auth/password/reset  # パスワードリセット
```

#### 経路検索 API

```
GET    /api/v1/routes/search        # 経路検索
  ?from=lat,lon&to=lat,lon&time=ISO8601&mode=TRANSIT,WALK

GET    /api/v1/routes/:id           # 経路詳細取得
POST   /api/v1/routes/favorites     # お気に入り保存
```

#### チケット API

```
POST   /api/v1/tickets              # チケット購入
GET    /api/v1/tickets/:id          # チケット詳細取得
GET    /api/v1/tickets              # チケット一覧取得
POST   /api/v1/tickets/:id/validate # チケット検証
DELETE /api/v1/tickets/:id          # チケットキャンセル
```

#### ユーザー API

```
GET    /api/v1/users/me             # 自身のプロフィール取得
PUT    /api/v1/users/me             # プロフィール更新
GET    /api/v1/users/me/trips       # 旅行履歴取得
GET    /api/v1/users/me/tickets     # チケット履歴取得
```

#### 交通データ API

```
GET    /api/v1/transit/stops        # 停留所一覧
GET    /api/v1/transit/stops/:id    # 停留所詳細
GET    /api/v1/transit/routes       # 路線一覧
GET    /api/v1/transit/routes/:id/realtime  # リアルタイム情報
```
