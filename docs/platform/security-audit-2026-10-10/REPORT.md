# OpenMaaS セキュリティ監査

ソース監査と修正後の独立レビューを実施。動的・配備済み環境の監査は未完了。指定スキルの完全な隔離条件を満たす実行環境を確立していないため、通常の開発テストをセキュリティ脆弱性の再現証拠に昇格させていない。

確定脆弱性0件、要検証1件。これは安全性の保証ではない。要検証は旧Service Worker登録と同一origin配備を条件とするアカウント間キャッシュ。現行workerを退役し旧OpenMaaSキャッシュを削除する修正を実装済み。severityは付けていない。

予防・耐障害修正：全外部JSON/GTFS読み取りのデコード後バイト上限、Luma/Square/Googleの50ページ上限と反復cursor拒否、公開login/活動詳細のレート制限、期限切れ認証レコード削除、CSV式文字のエスケープ、Web/APIレスポンスヘッダー。

所有者境界、OIDC/Google stateとPKCE、JWT検証、Webhook署名、Stripe金額照合、原子的券消費を追跡し、具体的な迂回経路は成立しなかった。供給網はsource/lockfile/CIを確認し、外部脆弱性データベースとの照合はしていない。

coverage-ledger.jsonは10領域のソース確認を示す。現行Cloudflareの実設定、依存先/IdPの権限、旧worker配備状態、ネイティブブラウザーでの隔離攻撃再現は対象外・未検証。全監査完了とは扱わない。
